# FO-02 – Grand Automotive Greek voice assistant (demo)

**Katerina**, a Greek voice assistant for Renault and Dacia in Greece (Grand Automotive Hellas), built by NDI on ElevenLabs
(Eleven v4 Turbo, native Greek voice). Visitors open the website and talk: no sign-up, no sign-in.

- `agent/` – the ElevenLabs agent (prompt and setup script)
- `knowledge_base/` – the 6 Greek PDFs of the knowledge base and the script that builds them
- `research/` – the public sources behind the facts
- `web/` – the website (Next.js), see `web/README.md` for Vercel

Project details and status: `CLAUDE_HANDOFF.md`.
